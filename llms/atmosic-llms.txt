# Atmosic Technologies

> Fabless semiconductor company (San Jose, CA) designing ultra-low-power Bluetooth LE and 802.15.4 system-on-chips for the Internet of Things, built around patented energy-harvesting and controlled wake-up receiver technology with the goal of eliminating device dependence on batteries. Atmosic publishes an EMBEDDED developer surface — the open-source OpenAir SDK on Zephyr RTOS, an AT command set over UART, an atm_isp protobuf schema, and desktop programming tooling — not a public web API. Contract discovery on 2026-08-02 found no OpenAPI, GraphQL, MCP server, AsyncAPI, agent card or /.well-known/ surface on any Atmosic host.

## Products

- [ATM2 Series](https://atmosic.com/products/): first-generation ultra-low-power Bluetooth LE SoCs
- [ATM3 Series](https://atmosic.com/products/): Bluetooth LE SoCs with energy harvesting
- [ATM33/e Series](https://atmosic.com/products/the-atm33-series/): Bluetooth LE 5.3 compliant, 64 MHz Arm Cortex-M33F, Arm TrustZone, hardware root of trust, secure boot; the /e variant adds energy harvesting. PSA Certified Level 1 (certificate 0632793520085-20033).
- [ATM34/e Series](https://atmosic.com/products_atm34/): Bluetooth LE 6.0 compliant plus 802.15.4, 64 MHz Arm Cortex-M33F with DSP, TrustZone, AES-128/256, SHA-2/HMAC-256, TRNG
- [Product Selector Guide](https://atmosic.com/products/)

## Source Code

- [GitHub organization](https://github.com/Atmosic)
- [openair](https://github.com/Atmosic/openair) — top-level SDK, a Zephyr west manifest. `west init -m https://github.com/Atmosic/openair.git zephyrproject`

- [hal_atmosic_lib](https://github.com/Atmosic/hal_atmosic_lib) — hardware abstraction layer (Apache-2.0)
